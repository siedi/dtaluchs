# DTA-Luchs

Auswertung der DTA-Dateien einer Wärmepumpe mit Luxtronik-Steuerung: Zeitreihen, Läufe des Verdichters, Abtauungen und Kennzahlen. Die App ruft die Datei selbst von der Steuerung ab und erscheint im Seitenmenü von Home Assistant.

Nur für Home Assistant OS. Mit Home Assistant Container läuft DTA-Luchs als eigener Container, siehe Repository.
